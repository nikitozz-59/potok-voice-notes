# Голосовые заметки (voice-notes) — production-прототип

Запись голоса на Amazfit Active → телефон → Nexara → расшифровка на часах.
Версия 0.1.0: списки заметок, статусы, авто-отправка, просмотр расшифровки,
очередь при офлайне, ключ Nexara вне исходников.

Архитектура и все находки спайков — в `../architecture.md`.
Настройка релея — в `../relay/README.md`.

## Состав

| Каталог | Что |
|---|---|
| `page/index.js` | Часы: список заметок, запись, очередь, просмотр текста |
| `app-side/index.js` | Side-service в Zepp App: JSON-прокси на релей |
| `../relay/relay.py` | Termux-релей: base64 → Zepp-OPUS → WAV → Nexara |
| `app.json` | appId 1131887, версия 0.1.0 (code 20), amazfit-active |

## Быстрый старт (после любой пересборки)

1. **Релей в Termux** (если ещё не запущен):
   ```bash
   python ~/relay.py
   ```
   Должно быть `ключ: найден` и `libopus: OK`. Настройка — `../relay/README.md`.

2. **Zepp App** на телефоне: открыть (полностью перезапустить из недавних!
   side-service кэшируется, иначе работает старая версия).

3. **Собрать и установить приложение** (с машины):
   ```bash
   cd voice-notes
   npm install          # первый раз
   npx zeus preview -t "Amazfit Active"
   ```
   Отсканировать QR-код в Zepp App → приложение установится на часы.

4. **Тест**: часы → «Голосовые заметки» → ● Записать → говорить 10–15с → ■ Стоп
   → заметка сама уходит в очередь → через 2–5с статус «готово» → тап по
   заметке → расшифровка.

## Экран

```
┌──────────────────────────┐
│  Релей: OK · заметок 3   │  ← шапка: связь + очередь / секунды записи
│ ┌──────────────────────┐ │
│ │ 14:32 · готово       │ │  ← список (скролл)
│ │ 1 2 1 2 3 проверка   │ │     тап → расшифровка
│ ├──────────────────────┤ │
│ │ 14:40 · в очереди    │ │
│ │ 15с · 36КБ · ждёт…   │ │
│ └──────────────────────┘ │
│  [ ● Записать ] [Отправить 1] │
│  Тап по заметке — расшифровка │
└──────────────────────────┘
```

Статусы: **в очереди** (записано, ждёт отправки) → **отправка…** → **готово**
(текст на часах, аудио удалено) либо **ОШИБКА** (тап → «Повтор»).

## Поведение

- **Авто-отправка**: после «Стоп» заметка сама уходит в Nexara (если релей жив).
- **Офлайн-очередь**: если релей/Zepp App недоступны — запись остаётся
  «в очереди» на часах. При следующем открытии приложения (или «Отправить»)
  очередь доочереживается. Аудио хранится до успешной расшифровки.
- **Не вытеснять молча**: при <60МБ свободно запись не начинается с предупреждением;
  при падении места посреди записи — автостоп с предупреждением.
- **Автостоп 120с** — защита от обрыва длинных записей. Чанкинг base64 по BLE
  реализован (куски по 2КБ с подтверждением каждого), проверено на 34с (80КБ
  opus → 107КБ base64 → 53 куска → HTTP 200). 120с (~380КБ base64, ~190 кусков)
  передаётся ~20–30с — в пределах таймаута.
- **Оборванная запись** (закрыли приложение во время записи) — сохраняется
  в очередь, не теряется.
- Расшифровка **сохраняется навсегда** (текст в `data://notes.json`), аудио
  удаляется после успеха. Удалить заметку с текстом — кнопка «Удалить» в
  карточке.

## Ограничения v0.1

- Запись только при **включённом экране** (фоновая запись — отдельный spike,
  см. architecture.md).
- Zepp App должен быть **открыт**, иначе side-service не отвечает.
- Длинные записи >2 минут режутся автостопом (лимит `MAX_REC_S=120`; чанкинг
  работает, но >120с не тестировалось — при желании поднимите константу).
- Нет поиска/папок/экспорта текста — только список и карточка.

## Диагностика

| Симптом | Что делать |
|---|---|
| «Релей: нет» | Запустите `python ~/relay.py`; перезапустите Zepp App из недавних |
| Заметка «ОШИБКА» | Тап → текст ошибки → «Повтор». `relay HTTP 503` = нет ключа |
| Старый код в Zepp App | Полностью закрыть Zepp App из недавних и открыть заново |
| Пустая расшифровка | Говорите ближе к часам, тише surroundings |
| Логи релея | Смотреть окно Termux (строки с временем) |

Пересборка QR: QR из `zeus preview` живёт ограниченное время — при истечении
просто выполнить команду заново.
